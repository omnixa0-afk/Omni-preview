# The Omni mark: "flowing ring"

Three equal arcs with no center, reflecting a network with no central node. The color of each arc flows into the
color of the next, so around the ring it neither begins nor ends. Parameters: rotation 30°, gap 26°,
stroke width 9, radius 34.

All files are generated by `make_logo.py`. The SVG, XAML and PNG files are not edited by hand; the
parameters in the script are changed and the files rebuilt:

- `python make_logo.py` writes the SVG files here;
- `python make_logo.py --assets` also writes the WinUI PNG set into `Assets/` and `Assets/Omni.ico`
  (the exe icon, `ApplicationIcon` in the csproj). It rasterizes through headless Edge (no SVG library
  is required) and downscales with PIL.

In the app the mark appears in the window title bar and on the taskbar button
(`MainWindow.ApplyWindowIcon`: the exe icon is applied to the window through `WM_SETICON`, because the
exe icon alone does not reach the window). The sidebar has no mark: it holds navigation only, and a
ring with gaps at 24 px read as a loading indicator.

`Assets/Square44x44Logo.targetsize-24_altform-unplated.png` is also the tray icon
(`Core/TrayIcon.cs`): a flat, colored, small version that reads on both dark and light taskbars.
The other PNGs (`Square150…`, `Wide310…`, `SplashScreen…`, `StoreLogo`, and the white `LockScreenLogo`)
are needed only by a packaged (MSIX) build; the app is currently distributed as an exe.

## Files

| File | Use |
|---|---|
| `omni-mark-gradient.svg` | mark with the color flow, no background; 32 px and up: app header, splash, website |
| `omni-mark-gradient-tile.svg` | the same on a `#0E1621` tile: app icon, Start tile, store |
| `omni-mark-flat-small.svg` | flat colors, thicker stroke, wider gaps; 24 px and below: taskbar |
| `omni-mark-flat-small-tile.svg` | the same on a tile: `Square44x44Logo` at 16-24 px |
| `omni-mark-mono.svg` / `-mono-small.svg` | single color (`currentColor`): print, watermarks, lock-screen icon |
| `omni-lockup-dark-bg.svg` / `-light-bg.svg` | mark plus the word "Omni" converted to outlines, for dark and light backgrounds |

## Rules

- **24/32 px threshold.** The color flow and the thin stroke do not survive small sizes: at 24 px and
  below only the `*-small` variants are used. The mark is not used below 16 px.
- **Clear space** around the mark is at least twice the arc thickness (18 units for the 84×84 master,
  which equals the margin of the tile version's `viewBox`).
- **No rotation.** At 0° or 120° one gap sits exactly at the top and the mark reads as a power button.
- **Colors:** `#3D7DFF` (the app accent), `#1FC3A0`, `#8B5CF6`. Transitions are computed in OKLCH,
  because in sRGB the midpoint of teal to violet turns gray. On the teal-to-violet arc the blue section
  is deliberately short; otherwise the ring becomes almost entirely blue.
- **The word** is set in Segoe UI Variable Display Semibold: its stroke weight matches the arcs, and
  the app headings use the same face. The files contain it as outlines, so no font is needed to view them.

## Open questions

- **Font license.** Segoe UI is a Microsoft font and its license is intended for use on Windows.
  For the word in the logo outside Windows (website, a future Android version) the terms need to be
  checked, or the font replaced with an open one of similar design (Inter SemiBold, Manrope SemiBold).
